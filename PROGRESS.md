# Прогресс проекта Telegram AI CRM

_Обновлено: 13.11.2026_

## Цель

Магазин продаёт товары на **Wildberries**. На упаковке каждого товара — **QR-код**.
Покупатель сканирует → попадает в Telegram-бота → AI-менеджер благодарит за покупку,
предлагает похожие/подходящие товары (кнопки ведут на карточки WB), выдаёт промокод WB
на следующий заказ и приглашает в канал.

- Бот: **@Miss_Way_bot** («MissWay Boot»)
- Канал: **@Miss_Way** (бот — админ канала)
- Админ бота (Telegram ID): `761517835`

## Что сделано ✅

| Функция | Где в коде |
|---|---|
| Backend на Python: FastAPI + PostgreSQL + Alembic | `app/api/`, `app/models.py`, `migrations/` |
| Telegram-бот на aiogram 3 | `app/bot/` |
| AI-менеджер на Claude API: консультации по каталогу, помнит покупки клиента, кнопки на товары WB | `app/ai/manager.py` |
| QR-коды для упаковки: `t.me/Miss_Way_bot?start=p<ID товара>` → благодарность + рекомендации | `app/services/qr.py`, `app/bot/handlers/start.py` |
| Промокод WB после сканирования QR (общий, из кабинета продавца WB) | `app/services/promo.py` |
| Проверка подписки на канал + автоучёт подписок/отписок | `app/services/subscription.py`, `app/bot/handlers/channel.py` |
| Рассылки: сразу или по расписанию — из бота, админки и API | `app/services/broadcasts.py`, `app/services/scheduler.py`, `app/bot/handlers/broadcast.py` |
| Учёт рекламы: ссылки `t.me/Miss_Way_bot?start=<метка>` | `app/bot/handlers/start.py` |
| Веб-админка (SQLAdmin, на русском) | `app/admin.py` |
| Подготовка к серверу: Docker Compose, HTTPS (Caddy), бэкапы, обновление | `docker-compose.yml`, `deploy/`, `DEPLOY.md` |

### Команды бота (только для админа)

- `/broadcast` — рассылка всем; `/broadcast <метка>` — клиентам одной кампании
- `/scheduled` — отложенные рассылки и их отмена
- `/cancel` — отменить ввод рассылки

### Разделы админки

Клиенты · Диалоги с AI · Покупки (QR) · Товары (кнопка «Скачать QR для упаковки») ·
Промокоды WB · Рекламные кампании · Рассылки

## Локальный запуск (Mac)

PostgreSQL 16 установлен через Homebrew и запущен как служба. Python 3.12 — в `.venv`.

```bash
cd "/Users/home/PycharmProjects/Telegram AI CRM "
.venv/bin/uvicorn app.api.main:app --reload   # API + админка: http://localhost:8000/admin
.venv/bin/python -m app.bot.main              # бот (не запускать одновременно с сервером!)
```

Логин админки и все ключи — в `.env` (в git не попадает).
